# Everyday orchestration integration

Source entry: `source/server/scripts/cercano-launcher.sh`; installed launcher is untouched. Installer remains explicit no-clobber. Source resolves its own repository; installer bakes the repository, with CERCANO_REPO override.

Set CERCANO_DEVELOPMENT_STATE to a canonical, owned 0700 directory exclusively provisioned with `/absolute/generation/cercano prepare-development --new-state /absolute/NEW/state`. Supply a deliberate owned 0600 `config.yaml`; never copy/adopt a legacy database. Normal launches require the prepared production declaration, publish canonical fingerprint generations with `--sign --reuse`, and execute only that generation's server and CLI. Credential access is disabled in child environments.

`development-launch --state ABS --generation ABS --runtime-root ABS` prints only the immutable per-invocation selection path. `main.go` dispatches both development-launch and the parallel agent's runDevelopmentHost. Host records are `state/hosts/SHA256(canonical-generation-path).json`; the corresponding `.token` is created exclusively with devhostauth. A `.lock` cross-process flock serializes readiness/acquisition, and `.starting` is a durable exclusive launch intent. Existing missing/unreachable/invalid records or unresolved start intents never authorize replacement. No automatic retirement policy is implemented. Verified retirement/reprovisioning is an explicit future operation, not reconnect behavior.

Host command: exact absolute generation/cercano development-host --state ... --generation ... --host RANDOM --token-file ... --record ... --runtime-root ... --listen 127.0.0.1:0. Detached session, no command-context lifetime, no PATH fallback. The host publishes its private record atomically after readiness. Orchestration authenticates LifecycleList with exact host/build/contract/schema/store identity, then explicitly LifecycleAcquire with a fresh random conversation. Selections include Generation plus the CLI DevHostSelection fields. Reconnect with --dev-host uses only the specified immutable selection under this state's selections directory and never builds or acquires.

Runtime root defaults to a private randomly-created canonical /tmp namespace, persisted in state/runtime-root.json under flock; override CERCANO_RUNTIME_ROOT must already exist, be owned/private/canonical and <=38 resolved bytes. Validation happens before building/spawning. Never remove runtime roots based on inferred process death.

Focused coverage: actual shell/Python entrypoint with fake publisher/server/CLI (signing arguments, concurrency, argument boundaries, preflight and host failures), no-clobber installer safety, and real Go orchestration in separate processes against an authenticated fake gRPC host (same-generation reuse, fresh immutable selections, unreachable-record fail-closed). Full production A/B PTY acceptance is not claimed.
